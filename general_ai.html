Поля таблицы

📋 Описание полей

Каждое поле таблицы NocoDB и его назначение в контексте галереи Broot.

Поле Тип Обязательно Описание
Id AutoNumber авто Первичный ключ, генерируется автоматически. Используется для сортировки записей.
user_name SingleLineText да Имя пользователя-автора. Отображается как @автор в карточке галереи.
broot_name SingleLineText да Имя персонажа (Broot). Отображается как заголовок карточки.
broot_avatar_link LongText да Data URL статичного SVG-аватара (base64). Используется как <img src>.
broot_avtor_name SingleLineText нет Отдельное поле для имени автора. Имеет приоритет над user_name при отображении.

Методы API

📥 GET — список записей

Получить все записи галереи с сортировкой по убыванию ID.

GET /api/v2/tables/m2ockzkupf65cre/records?limit=200&sort=-Id
xc-token: i6hxbF...

➕ POST — создать запись

Добавить нового персонажа в галерею.

POST /api/v2/tables/m2ockzkupf65cre/records
xc-token: i6xbF...
Content-Type: application/json

[{
  "user_name": "verifure",
  "broot_name": "halo",
  "broot_avatar_link": "data:image/svg+xml;base64,...",
  "broot_avtor_name": "verifure"
}]

✏️ PATCH — обновить запись

Обновить поля существующей записи по ID.

PATCH /api/v2/tables/m2ockzkupf65cre/records/{id}
xc-token: i6xbF...
Content-Type: application/json

[{
  "Id": 1,
  "broot_name": "new-name"
}]

🗑 DELETE — удалить запись

Удалить запись по ID (массово).

DELETE /api/v2/tables/m2ockzkupf65cre/records
xc-token: i6xbF...
Content-Type: application/json

[{ "Id": 1 }]

Руководство по интеграции

🔌 Подключение Broot к вашему проекту

Broot можно встроить в любое веб-приложение. Компоненты редактора экспортируются как отдельные HTML-фрагменты, а SVG-аватары можно рендерить на сервере или в браузере.

1. Редактор

Вкладка «Редактор» генерирует JSX или HTML-код для вставки в ваш проект. Скопируйте его из секции «Код».

2. Компоненты

Секция «Компоненты» содержит готовые фрагменты: аватары присутствия, список агентов, таблицу пользователей, поле пароля и групповой чат.

3. Галерея

Записи хранятся в NocoDB. Используйте REST API для чтения и записи. Токен и ID таблицы — в разделе «Конфигурация».

4. Telegram

Авторизация через Telegram Login Widget. Данные пользователя сохраняются в localStorage и используются как имя автора при сохранении в галерею.
